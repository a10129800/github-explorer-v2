# GitHub Explorer V2｜開源專案雷達

探索 GitHub 開源專案、掌握技術趨勢，並更方便地整理與研究感興趣的專案。

## 📥 下載 Windows 版本

**[前往 Releases 下載最新版本](https://github.com/a10129800/github-explorer-v2/releases)**

### 安裝方式

1. 下載 `GitHub-Explorer-Setup.exe`。
2. 雙擊安裝檔，依照畫面指示完成安裝。
3. 啟動 GitHub Explorer V2，依照軟體提示進行設定。

## ✨ 主要功能

- 🔎 **探索開源專案**：搜尋與瀏覽 GitHub 上的專案。
- 📊 **專案分析**：查看專案資訊，協助了解專案狀況。
- 🔥 **技術情報**：探索值得關注的開源趨勢與專案。
- 🤖 **AI 輔助工具**：使用軟體提供的 AI 相關功能。
- ⭐ **收藏與整理**：管理感興趣的專案。

> 實際可用功能依目前發布版本為準。

## ⚙️ 使用前須知

- 部分功能可能需要設定 GitHub Token 或 AI API Key，請依照軟體內的提示操作。
- 請妥善保管個人 Token 與 API Key，不要公開分享。
- 若 Windows 顯示安全性警告，請先確認下載來源，再決定是否執行安裝程式。
