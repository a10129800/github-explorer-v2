### 專案介紹

GitHub Explorer V2 是一款用來探索 GitHub 開源專案的工具，希望讓使用者更方便地發現、瀏覽與探索有趣的專案。

### 為什麼我需要這套工具？

GitHub 上有大量優秀的開源專案，但當我想尋找有趣、實用或值得研究的專案時，經常需要在不同的頁面之間切換，反覆搜尋、閱讀與整理資訊。

我希望能有一套工具，讓探索 GitHub 專案這件事變得更直覺、更有效率，也更有趣。

因此，我開始製作 **GitHub Explorer V2**，希望將專案探索與相關功能整合在一起，減少尋找資訊的時間，讓我能把更多精力放在發掘值得關注的開源專案上。

這不只是一個用來瀏覽 GitHub 的工具，也是我嘗試改善自己工作流程、探索開源世界的實踐。

#### 我希望它能帶來什麼？

- **減少搜尋成本：** 讓尋找與探索 GitHub 專案的過程更加方便。
- **改善探索體驗：** 讓發現新專案不再只是反覆搜尋與切換網頁。
- **集中管理資訊：** 讓專案探索流程更加有條理。
- **持續改善與擴充：** 根據使用需求，逐步改善功能與使用體驗。

我希望這套工具不只對我自己有幫助，也能讓其他喜歡探索開源專案的人找到適合自己的工具與靈感。

### 下載與安裝

前往 [GitHub Releases](https://github.com/a10129800/github-explorer-v2/releases) 下載最新版 Windows 安裝檔。

1. 進入 Releases 頁面。
2. 找到最新版本。
3. 下載 `GitHub-Explorer-Setup.exe`。
4. 執行安裝檔，依照畫面指示完成安裝。

## 🇺🇸 English

### About

GitHub Explorer V2 is a tool for exploring GitHub open-source projects. Its goal is to make discovering and browsing interesting projects more convenient.

### Why Do I Need This Tool?

GitHub hosts a huge number of excellent open-source projects. However, finding interesting, useful, or worthwhile projects often means switching between pages, searching repeatedly, and organizing information manually.

I wanted a tool that could make exploring GitHub projects more intuitive, efficient, and enjoyable.

That is why I started building **GitHub Explorer V2**. My goal is to bring project exploration and related features together, reduce the time spent searching for information, and spend more time discovering open-source projects worth exploring.

This project is more than a GitHub browsing tool. It is also my attempt to improve my own workflow and explore the open-source world in a more organized way.

#### What Do I Hope It Can Achieve?

- **Reduce search effort:** Make finding and exploring GitHub projects more convenient.
- **Improve discovery:** Make discovering new projects easier than repeatedly searching and switching between web pages.
- **Organize the workflow:** Make the project exploration process more structured.
- **Keep improving:** Gradually enhance features and usability as needs evolve.

I hope this tool can be useful not only to me, but also to others who enjoy exploring open-source projects and discovering new ideas.

### Download and Installation

Visit [GitHub Releases](https://github.com/a10129800/github-explorer-v2/releases) to download the latest Windows installer.

1. Open the Releases page.
2. Find the latest release.
3. Download `GitHub-Explorer-Setup.exe`.
4. Run the installer and follow the on-screen instructions.
