## 繁體中文

### 專案介紹
GitHub Explorer V2 是一款用來探索 GitHub 專案的工具。

### 下載與安裝
前往 [GitHub Releases](https://github.com/a10129800/github-explorer-v2/releases) 下載最新版 Windows 安裝檔。

下載 `GitHub-Explorer-Setup.exe`，執行後依照畫面指示安裝。

### 使用說明
請參閱 [桌面版使用指南](docs/DESKTOP_EXE_USER_GUIDE.md)。

### 回報問題
如果遇到問題，請前往 [Issues](https://github.com/a10129800/github-explorer-v2/issues) 回報。

## English

### About
GitHub Explorer V2 is a tool for exploring GitHub projects.

### Download and Installation
Visit [GitHub Releases](https://github.com/a10129800/github-explorer-v2/releases) to download the latest Windows installer.

Download `GitHub-Explorer-Setup.exe` and follow the on-screen instructions.

### User Guide
See the [Desktop User Guide](docs/DESKTOP_EXE_USER_GUIDE.md).

### Report an Issue
If you encounter a problem, please report it on [GitHub Issues](https://github.com/a10129800/github-explorer-v2/issues).
