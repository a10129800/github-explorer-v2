## 1. 開發者：如何產生 Windows 安裝包 EXE

在您的開發電腦上，您可以使用我們準備好的**無終端機一鍵打包工具**，輕鬆產生正式安裝程式：

### 方法 A：使用一鍵 BAT（最簡單、推薦）
1. 開啟專案根目錄。
2. 找到並**雙擊執行「`建立Windows安裝版.bat`」**。
3. 腳本會自動完成：
   * 檢查 Node.js 與必要依賴。
   * 自動以官方高解析度素材生成多解析度 Windows 圖標（`build/icon.ico`，支援 16/32/48/256px）。
   * 編譯 Next.js Standalone 生產版（`next build`）。
   * 整理靜態資產與 Prisma 資料庫結構。
   * 透過 `electron-builder` 打包為 Windows NSIS 安裝精靈。
4. 打包完成後，視窗會清楚顯示檔案大小、完整路徑與 SHA-256 驗證碼。

> 💡 **單獨更新圖標**：若您想單獨重新產出最新圖標檔案，也可以隨時雙擊根目錄的 **「`生成圖標.bat`」**。

### 方法 B：使用 npm 指令
若您習慣使用終端機，亦可在專案目錄中執行：
```bash
npm run dist:win
```

### 產物位置：
* **安裝程式檔名**：`GitHub-Explorer-Setup.exe`
* **完整檔案路徑**：`專案目錄\dist\GitHub-Explorer-Setup.exe`

## 2. 使用者：軟體安裝步驟

當您取得 `GitHub-Explorer-Setup.exe` 安裝檔後，在任何 Windows 10 / 11 電腦上皆可直接安裝（**電腦不需要事先安裝 Node.js**）：

1. **雙擊執行** `GitHub-Explorer-Setup.exe`。
2. **安裝精靈介面**：
   * 歡迎使用 GitHub Explorer V2 安裝程式。
   * 點選「下一步」。
3. **選擇安裝路徑**：
   * 預設安裝於目前使用者的應用程式資料夾（無需系統管理員權限）。
   * 您也可以點選「瀏覽」自訂安裝磁區與資料夾。
4. **捷徑設定**：
   * 勾選「建立桌面捷徑」（預設已勾選）。
   * 勾選「建立開始功能表捷徑」（預設已勾選）。
5. **開始安裝**：
   * 點選「安裝」，進度條完成後即可點選「完成」並立即啟動軟體！

## 3. 日常使用與操作說明

### 啟動應用程式
* 直接雙擊桌面的 **「GitHub Explorer V2」** 藍紫色雷達捷徑圖示。
* 軟體啟動時會先顯示短暫的精緻啟動畫面（Splash Screen），本機伺服器就緒後會平滑展開主視窗。

### 外部連結安全開啟
* 在軟體中點擊任何開源專案的「GitHub 官方連結」、「線上 Demo 網址」或「作者首頁」時，系統會自動呼叫您的 **Windows 預設瀏覽器（如 Edge、Chrome、Brave）** 開啟，確保桌面軟體主體安全與流暢。

### 視窗控制與關閉
* 支援標準 Windows 視窗操作：最小化、最大化、縮放調整與關閉。
* **關閉應用程式時**：點擊右上角的「✕」關閉按鈕，系統會自動優雅停止本機背景服務，不會留下任何幽靈程序占用電腦記憶體。

## 4. 資料庫位置與個人資料保護

為避免安裝在 `C:\Program Files` 時因 Windows 系統權限導致資料無法儲存，正式版軟體嚴格遵循 Windows 軟體規範，將您的個人資料庫隔離儲存於：

* **資料庫存放路徑**：  
  `%APPDATA%\GitHub Explorer V2\radar.db`  
  *(實際路徑：`C:\Users\<您的電腦使用者名稱>\AppData\Roaming\GitHub Explorer V2\radar.db`)*

### 資料保護承諾：
1. **升級軟體不掉資料**：未來安裝新版本覆蓋時，系統會自動保留現有資料庫。
2. **解除安裝保護**：即使您從 Windows「新增或移除程式」解除安裝，系統**預設不會刪除** `%APPDATA%` 中的資料庫與收藏紀錄，避免誤刪珍貴資料。
3. **資料備份**：若需更換電腦，只需複製上述路徑中的 `radar.db` 檔案至新電腦相同路徑即可還原所有收藏與設定！

## 5. 常見問題與排錯診斷

### Q1：首次啟動時如果 Windows Defender 或智慧篩選（SmartScreen）出現提示？
* **說明**：由於這是由您本機編譯打包的軟體，尚未購買昂貴的微軟商業憑證進行代碼簽署（Code Signing）。
* **操作方式**：點擊視窗上的 **「其他資訊」** ➔ 再點擊 **「仍要執行」** 即可正常安裝與啟動。

### Q2：若啟動畫面停留較久或顯示錯誤？
* 軟體內建即時診斷日誌，您可以前往查看詳細伺服器啟動紀錄：  
  `%APPDATA%\GitHub Explorer V2\logs\server.log`
* 檢查是否有其他軟體嚴重占用本機迴圈網路（Loopback）連接埠。

## 6. 如何繼續使用原本的網頁版開發模式

本專案採用**完全無損架構設計**，桌面化封裝完全不影響原本的網頁版使用：

* 若您想以一般網頁模式執行：  
  隨時直接雙擊專案根目錄的 **`一鍵啟動.bat`** 即可！
* 網頁開發版與桌面安裝版各自使用獨立的埠號與資料庫配置，可並存使用，互不衝突。
