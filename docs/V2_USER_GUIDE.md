# GitHub Explorer V2 — 使用者操作指引 (User Guide)

歡迎使用 **GitHub Explorer V2（開源專案雷達）**！本指南將帶您快速上手各項全新功能。

---

## 一、Windows 一鍵啟動方式

對於 Windows 桌面使用者，整個專案已預先封裝好極簡啟動流程：

1. **第一次使用**：
   - 點擊專案目錄下的 `安裝依賴.bat`（或直接執行 `一鍵啟動.bat`，系統會自動偵測並安裝）。
2. **日常啟動**：
   - 只要雙擊 `一鍵啟動.bat`。
   - 系統會自動檢查環境、防撞連接埠（3000/3001）、編譯 Prisma 資料庫模型，並在您的預設瀏覽器中自動開啟 `http://localhost:3000`（或 `http://localhost:3001`）。
3. **停止服務**：
   - 在終端機視窗中按下 `Ctrl + C`，或直接關閉該命令提示字元視窗即可。

## 二、八大新功能操作指南

### 1. 免費 AI 工具尋寶 (`/ai-tools`)
- **功能特色**：分類彙整文字轉影片、圖片生成、本機 LLM、語音合成 (TTS)、口型同步與 3D 生成等 AI 開源專案。
- **操作方式**：
  - 點選左側側邊欄的「AI 工具尋寶」。
  - 點選上方分類標籤（如「AI 文字轉影片」或「本機大型語言模型」）。
  - 使用屬性勾選列：例如勾選「無需獨立 GPU」可立即找出可在文書筆電執行的專案；勾選「僅完全免費自架」過濾掉需自備付費 API 的專案。

### 2. Demo 一鍵試玩體驗
- **功能特色**：無須下載幾十 GB 權重或繁瑣安裝，直接在瀏覽器開啟官方認證之線上展示。
- **操作方式**：
  - 在任何專案卡片或專案詳情頁中，點選「Demo 一鍵試玩體驗」或藍色播放按鈕。
  - 系統彈出安全檢查視窗，標示該 Demo 是「已驗證官方展示」或「未充分驗證」。
  - 提供一鍵複製網址或在新分頁直接開啟。

### 3. 同類專案比較器 (`/compare`)
- **功能特色**：支援 2～4 個 GitHub 專案橫向對比。
- **操作方式**：
  - 點選側邊欄「專案比較器」，或在任何專案卡片點擊「加入比較」圖示。
  - 輸入候選專案（如 `AUTOMATIC1111/stable-diffusion-webui` 與 `Comfy-Org/ComfyUI`）。
  - 系統即時比對 Stars、授權、Windows 相容度、GPU/算力需求、安裝難度，並依據「快速試玩」、「生產穩定度」與「低算力成本」提供場景化推薦。

### 4. README 繁體中文結構化解說
- **功能特色**：無需逐段閱讀冗長英文 README，規則引擎自動抽取 11 項關鍵指標。
- **操作方式**：
  - 點入任何專案詳情頁（例如點擊首頁或搜尋清單中的專案）。
  - 頁面中央即呈現繁體中文解說區塊，支援三種模式：
    - **快速理解**：摘要核心用途、適合情境與主要功能。
    - **安裝教學**：Windows 原生或 WSL2 推薦安裝步驟。
    - **技術細節**：已知限制、GPU 門檻與授權條款。
  - 點擊「複製解說內容」可一鍵複製結構化繁體中文筆記。

### 5. 每日開源情報與排程 (`/daily-intel`)
- **功能特色**：每日以台北時區 (`Asia/Taipei`) 彙整最新崛起與熱門專案，零捏造成長率。
- **操作方式**：
  - 點選側邊欄「每日開源情報」。
  - 瀏覽四大專區：今日熱門、新興潛力星、AI 工具專區與免安裝 Demo 專區。
  - 點擊「立即手動重整」可強制刷新最新資料。
  - 點擊「匯出 Markdown」或「JSON」可離線保存或分享至社群。
  - （選用）可執行 `scripts/schedule_intel.ps1` 輔助將更新作業掛載至 Windows 工作排程器。

### 6. AI 專案研究助手 (`/assistant`)
- **功能特色**：以白話中文提出技術探索需求，助手自動檢索、篩選並產出研究報告。
- **操作方式**：
  - 點選側邊欄「AI 研究助手」。
  - 在輸入框輸入中文（例如：「幫我找不用付費 API 的 AI 影片生成專案」或點選推薦範例）。
  - 系統解析意圖後查詢 GitHub，整理出優劣勢、硬體需求與優先推薦排行。

### 7. 相似專案推薦
- **功能特色**：在專案詳情頁底部自動運算 Topics、語意與生態相似之替代專案。
- **操作方式**：
  - 進入專案詳情頁底部即可看到「相似專案推薦與替代方案」。
  - 卡片清楚標記相似程度（如「極高相似 (85%)」）、相似原因（同技術棧、共享標籤）與主要差異。

### 8. Windows／硬體相容性評估 (`/compatibility`)
- **功能特色**：在安裝前評估個人電腦硬體是否足以順暢運作該專案。
- **操作方式**：
  - 點選側邊欄「硬體相容評估」。
  - 設定您的作業系統、RAM 容量、GPU 品牌、VRAM 大小與 WSL2/Docker 安裝狀態（系統會自動儲存於瀏覽器）。
  - 輸入目標專案名稱並點選「進行相容性分析」。
  - 查看判定等級（可直接使用 / 需額外硬體 / 大致相容），並取得 Windows 原生或 WSL2 最佳安裝步驟指引。

## 三、常見問題與排錯 (FAQ)

1. **Q: 啟動時提示連接埠 3000 已被占用？**
   - A: 我們的 `start.ps1` 具備自動防撞功能，會自動改用 `http://localhost:3001` 並為您自動開啟瀏覽器，無須手動殺除行程。

2. **Q: 沒有設定 GitHub Token 可以使用嗎？**
   - A: 可以。本系統完全支援無 Token 基本探索模式。若需高頻率密集搜尋，可在 `.env` 檔案中加入 `GITHUB_TOKEN=ghp_xxxx`（個人免費 Personal Access Token 即可），將每小時 API 限制提升至 5,000 次。

3. **Q: 本地資料庫在哪裡？如何重置？**
   - A: 本專案採用輕量 SQLite，資料庫檔案位於專案根目錄下的 `dev.db`。若資料庫有任何變動，系統均採用安全非阻塞降級設計，不會中斷網站運作。
