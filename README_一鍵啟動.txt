=======================================================
   GitHub Explorer V2 — 開源專案雷達 Windows 一鍵啟動說明
   Discover What's Rising in Open Source
=======================================================

歡迎使用「開源專案雷達」！如果您不熟悉命令列終端機操作，
只要依照下列步驟，雙擊滑鼠就能輕鬆啟動網站。

-------------------------------------------------------
【步驟一：準備環境（僅初次需要）】
-------------------------------------------------------
本專案基於 Next.js 全端架構，電腦中需具備 Node.js 執行環境：
1. 若您尚未安裝 Node.js，請至官方網站下載「LTS（長期支援版）」：
   官方下載網址：https://nodejs.org/
2. 下載後直接執行安裝程式，一路點選「Next」完成安裝即可。

-------------------------------------------------------
【步驟二：安裝專案套件（初次或更新時執行）】
-------------------------------------------------------
1. 在專案資料夾中，找到並滑鼠雙擊「安裝依賴.bat」。
2. 程式會自動檢查環境，並下載所需之相依套件與資料庫工具。
3. 初次安裝通常需時 1 至 3 分鐘，安裝完成後會顯示「安裝成功」，
   依提示按下任意鍵即可關閉視窗。

-------------------------------------------------------
【步驟三：一鍵啟動網站】
-------------------------------------------------------
1. 在專案資料夾中，滑鼠雙擊「一鍵啟動.bat」。
2. 視窗會自動檢查目錄、依賴與連接埠，並啟動開發伺服器。
3. 當視窗內出現：
   - Local: http://localhost:3000
   - Ready in ...
   即表示網站已成功在您的電腦上運作！

-------------------------------------------------------
【步驟四：在瀏覽器開啟網站】
-------------------------------------------------------
打開您常用的網頁瀏覽器（如 Chrome、Edge、Firefox 等），
在網址列輸入並前往：
http://localhost:3000
（如果 3000 埠被其他程式占用，終端機日誌會提示實際網址，例如 http://localhost:3001）

-------------------------------------------------------
【步驟五：如何停止網站】
-------------------------------------------------------
若您使用完畢想要停止伺服器：
1. 點一下黑色的啟動命令提示字元視窗。
2. 在鍵盤上同時按下 [Ctrl] + [C]。
3. 詢問是否終止批次檔時輸入「Y」，或直接點選視窗右上角的「X」關閉視窗即可。

-------------------------------------------------------
【步驟六：如何查看錯誤訊息】
-------------------------------------------------------
所有啟動批次檔皆已加入防閃退機制（保留視窗）。
若啟動或建置遇到問題，視窗不會突然關閉，您可以直接檢視視窗中輸出的
紅色或警告訊息，並將訊息複製以利排查。

-------------------------------------------------------
【步驟七：設定 GitHub Token（解除 API 每小時 60 次限制）】
-------------------------------------------------------
GitHub 對於未提供 Token 的公開存取限制為每小時 60 次請求。
若您希望解除限制（提升至每小時 5,000 次）：

1. 在專案根目錄中找到「.env.example」檔案。
2. 複製一份並重新命名為「.env」。
3. 使用記事本開啟「.env」，在 GITHUB_TOKEN= 後面貼上您的 Token：
   GITHUB_TOKEN=ghp_xxxxxxxxxxxxxxxxxxxx
4. 儲存檔案後，重新執行「一鍵啟動.bat」即可自動生效。

【安全注意事項（極重要）】：
- GitHub Token 屬於機密金鑰，本專案已嚴格設計將其存放在後端伺服器環境變數中，
  絕不會洩漏到瀏覽器前端程式碼。
- 嚴禁將包含您真實 Token 的「.env」或「.env.local」檔案上傳或提交至 GitHub。
  專案的 .gitignore 已將其預設排除。
